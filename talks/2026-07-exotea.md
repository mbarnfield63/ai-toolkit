# Agentic workflows

**Date:** 14 July 2026. **Event:** ExoTea, an informal research group talk. **Audience:** researchers who had used chatbots, most of them not yet coding agents. **Length:** 29 slides.

## What it covered

I opened by asking the room about long chatbot conversations: the point where the model goes round in circles, forgets what you told it, or suggests the fix it already tried. The rest of the talk was about how a coding agent with the right files around it avoids that.

- **Claude Code** as a local agent that works directly in your file system, one agent per project. See [CLAUDE.md and skills](../guide/02-claude-md-and-skills.md).
- **CLAUDE.md**: write one, start from `/init`, or copy someone else's. I showed the one for my quantum-number prediction project.
- **The vault**: a state file and a log file per project in Obsidian, with "get up to speed" and "save state" as the two key phrases. See [vault memory](../guide/03-vault-memory.md).
- **Why bother**: token limits. Commit, save state, then `/clear`, so each new chat starts from a short summary instead of a long history.
- **Skills and plugins**: [graphify](../kit/graphify.md), [ponytail](../kit/ponytail.md), [grilling](../kit/grilling.md) and [tdd](../kit/tdd.md). The grilling demo was a planning session for a fantasy football tool that took 23 questions to reach a plan.
- **Hooks**: ponytail's rules load at every session start; graphify rebuilds the project graph after every commit.
- **Model choice**: Sonnet as the daily driver, Opus or Fable chosen by task type, not project size. See [choosing a model](../guide/04-daily-workflow.md#choosing-a-model).
- **Agents**: listed as future work, with a plan to use Fable as an orchestrator that spawns Sonnet workers.

Takeaways on the last slide: context, context, context; garbage in, garbage out; isolate your projects; keep saving logs; it changes constantly.

## What has changed since

- The orchestrator is no longer future work. See [many agents on one project](../guide/05-multi-agent.md).
- Several agents at once needed a way to watch them: [the cockpit](../guide/06-cockpit.md).
- Every tool now has a [kit](../kit/README.md) page with how often I actually use it.
