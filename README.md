# AI Toolkit

How I work with AI coding agents day to day: the setup and the tools. I'm a PhD student in molecular spectroscopy, and most of this grew out of running a research pipeline with Claude Code.

This is a living record. When I start or stop using a tool, it changes here.

## Contents

- **[Guide](guide/)**: the story, in reading order. From one agent in one folder to an orchestrator with many workers.
- **[Kit](kit/)**: one page per tool I use (hooks, skills, plugins, command-line tools, apps), each with how often I use it.
- **[Examples](examples/)**: worked runs, shown step by step.
- **[Talks](talks/)**: the talks this material came from.

The same content is on my website at [mbarnfield63.github.io/toolkit](https://mbarnfield63.github.io/toolkit/).
